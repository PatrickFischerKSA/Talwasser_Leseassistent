# PDFs umbenennen (einmalig)

Deine PDFs heissen aktuell offenbar **Talwasser_I:1.pdf** usw. (mit Doppelpunkt). Das ist für Links/URLs mühsam.

Bitte benenne sie so um und lege sie ins **Root** des Repos:

- `Talwasser_I_1.pdf` bis `Talwasser_I_22.pdf`
- `Talwasser_II_1.pdf` bis `Talwasser_II_30.pdf`

Wenn du macOS verwendest, geht das am schnellsten so:

1. Finder öffnen → Ordner mit den PDFs
2. PDFs markieren → Rechtsklick → **Umbenennen…**
3. Suche `Talwasser_I:` → ersetze durch `Talwasser_I_`
4. (gleiches für `Talwasser_II:` → `Talwasser_II_`)

Wichtig: Die Zahl **muss** gleich bleiben (1…22 bzw. 1…30).
